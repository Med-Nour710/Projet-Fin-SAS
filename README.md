# Railway Manager

A simple Node.js console application for managing train trips and tickets.

## Features

- Display all available trips
- Buy a ticket with automatic seat assignment
- Display all purchased tickets
- Cancel a ticket
- Search tickets by passenger name
- Filter trips by departure city
- Sort trips by price

## Technologies Used

- JavaScript
- Node.js
- `prompt-sync`

## Prerequisites

**Node.js**  
**npm** 
**prompt-sync**
